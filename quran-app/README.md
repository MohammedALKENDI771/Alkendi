# 📱 تطبيق قرآن تدبُّر | Quran Tadabbur

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) يعرض **القرآن الكريم كاملاً بالرسم العثماني**
مع **مادة تدبرية لكل سورة** بأسلوب إيماني تربوي مستوحى من منهج الشيخ **محمد المقرمي**
(وقفات تدبرية + هدايات عملية + عمل بالآية + سؤال للتفكر)، وبألوان إسلامية جميلة:
زمردي عميق 💚 + ذهبي ✨ + كريمي 🤍 — مع وضع ليلي.

> ⚠️ **تنبيه منهجي وأمانة علمية:** نصوص التدبر في هذا التطبيق **محتوى تربوي أصلي**
> كُتب خصيصاً له، مستوحى من *منهج* الشيخ المقرمي في التدبر، وليست نقلاً حرفياً
> من كتبه أو دروسه. للاستزادة ارجع لمؤلفات ودروس الشيخ.

## ⬇️ التحميل والتثبيت (جاهز الآن)

**ملف التثبيت:** [`releases/quran-tadabbur-v1.0.0.apk`](../releases/quran-tadabbur-v1.0.0.apk)
الحجم ~16MB — يعمل بدون إنترنت — أندرويد 7.0 فأحدث (API 24+).

### خطوات التثبيت على هاتفك:
1. انسخ ملف `quran-tadabbur-v1.0.0.apk` إلى هاتفك (واتساب/تيليجرام/USB/Drive).
2. افتح الملف من مدير الملفات واضغط **تثبيت**.
3. إذا طلب السماح بـ **"التثبيت من مصادر غير معروفة"** اضغط سماح لمرة واحدة.
4. افتح التطبيق 📖 واستمتع بالتلاوة والتدبر.

### التحقق من الملف:
```bash
apksigner verify --print-certs releases/quran-tadabbur-v1.0.0.apk
aapt dump badging releases/quran-tadabbur-v1.0.0.apk | head -5
# package: name='com.alkendi.quran' versionName='1.0.0'
```

## 🛠️ البناء من المصدر

```bash
export ANDROID_SDK_ROOT=/tmp/android-sdk
# ثبت: platform-tools, platforms;android-34, build-tools;34.0.0
gradle :app:assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

- `compileSdk 34` — `minSdk 24` — Kotlin `2.0.21` — AGP `8.5.2` — Gradle `8.7`
- البيانات في `app/src/main/assets/`: `quran_compact.json` + `tadabbur_surah.json` + `tadabbur_ayah.json`
- المصدر: `app/src/main/java/com/alkendi/quran/`
